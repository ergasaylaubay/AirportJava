# AirportJava — Әуе билеттерін брондау

Java 17+, Maven, консольдық оқу жобасы. Төлем — шартты, нақты ақша алынбайды.

## IntelliJ IDEA арқылы іске қосу

1. Архивті жаңа қапшыққа шығар. Бұрынғы жобаңды сақтап қой.
2. IntelliJ IDEA → Open → осы қапшықтағы `pom.xml` файлын аш.
3. Project SDK және Maven JDK үшін JDK 17 немесе жаңасын таңда.
4. Maven жобасын қайта жүктеп, тәуелділіктердің жүктелуін күт.
5. `src/main/java/kz/airport/Main.java` ішіндегі `main()` әдісін іске қос.
6. Run конфигурациясындағы Working directory — осы `pom.xml` тұрған қапшық.

`Main.java` негізгі кіру нүктесі болып қалды. Файлдарды бөлек қолмен іске қосудың қажеті жоқ.

## Демо және бұрынғы деректер

Архивтегі бастапқы `data/airport.json` деректері өзгертілмеген. Оның рейстері өткен күнге тиесілі болуы мүмкін: оларды көруге болады, бірақ жаңа бронь жасалмайды.

Жаңа демо үшін тек жобаның бөлек сынақ көшірмесінде `data/airport.json` файлын `airport-backup.json` деп қайта ата. Келесі іске қосқанда DemoData ағымдағы күннен 7–8 күн кейінгі рейстерді жасайды. Негізгі жоба деректерін өшірме. Қалпына келтіру үшін бағдарламаны тоқтатып, жаңа airport.json-ды бөлек сақтап, backup атауын кері қайтар.

## Құрылым

| Класс | Міндеті |
|---|---|
| Main | Іске қосу, мәзір, әрекет шақыру, қате хабарлау |
| ConsoleInput | Мәтін мен сан енгізуді тексеру |
| DemoData | Файл жоқ кезде ғана үлгі рейстер мен тарифтер құру |
| BookingService | Броньдау, сыйымдылық, іздеу, төлем және қалпына келтіру |
| Booking | Бір броньның деректері мен күй ауысулары |
| Airport, Flight, Seat, Passenger, Fare | Пәндік деректер |
| Ticket | Абстракт билет |
| EconomyTicket, BusinessTicket | Ticket мұрагерлері, полиморфизм |
| FareCalculator | Есептеу интерфейсі |
| StandardFareCalculator | Тариф + қосымша багаж формуласы |
| JsonStorage | JSON v1 сақтау және оқу |
| BookingException | Өз ерекше жағдай класы, бастапқы қатені сақтау |
| Validation | Міндетті мәтінді тексеретін пакет ішіндегі көмекші |

17 класс (Ticket абстракт класын қосқанда) және 1 интерфейс. ArrayList рейстер/билеттерге, HashMap броньдарды кодпен табуға қолданылады.

## Тесттер

JDK және Maven бар ортада:

```sh
mvn test
mvn package
```

Немесе IntelliJ-де `src/test/java/kz/airport/AirportJavaTest.java` класын іске қос.
13 JUnit тестінің қамтуы мен орындалған тексерулер: [docs/TEST_RESULTS.md](docs/TEST_RESULTS.md).

## Код сапасын қорғау

Өзгерістер және не көрсету керегі: [docs/CODE_QUALITY.md](docs/CODE_QUALITY.md).
Архивте бастапқы Research/UML болмаған. GitHub-тағы бұрынғы `research.md` және `docs/uml` файлдарын сақта; жаңа көмекші кластар мен әдістерді Class UML-ға сәйкестендір.
Әкімші, рейс іздеу, орын таңдау және отырғызу талоны осы қысқартылған мәзірге қосылмаған. Тіркелу әдістері тарихи CHECKED_IN деректерін оқу үшін сақталған.
