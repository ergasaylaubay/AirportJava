# Тексеру нәтижелері — 24.11.2026

## Орындалған тексерулер

- Барлық production/test Java кодтары Eclipse Java Compiler арқылы Java 17 деңгейінде компиляцияланды, қате жоқ.
- OpenJDK 21 ортасында JUnit Console арқылы **13 тесттің 13-і өтті**.
- Maven бұл ортада орнатылмаған, сондықтан `mvn test` / `mvn package` іске қосылған жоқ. pom.xml-ге JUnit Jupiter және Surefire конфигурациясы қосылды; Maven жинағын IntelliJ-де тексеру керек.
- Нақты консоль сценарийі: Economy + 1 багаж → 38 000 теңге → төлем → төленген броньды жоюға тыйым → сақтау → қайта іске қосу → сол бронь/билетті табу. Өтті.
- Жіберілген бастапқы airport.json жеке уақытша көшірмеде оқылып, қайта сақталды. Барлық бронь өрістері сақталды (JSON тізімінің реті маңызды емес). Өтті.
- Бұзылған JSON-мен іске қосу: бағдарлама тоқтады, файл өзгертілмеді. Өтті.
- Негізгі деректер файлы өзгертілген жоқ. Сынақтар уақытша қапшықтарда орындалды.

## JUnit қамтуы

1. Economy және Business бағасы, қосымша багаж.
2. Теріс багаж саны қабылданбайды, бронь қосылмайды.
3. Өткен рейске жаңа броньға тыйым; тарихи броньды қалпына келтіру рұқсат.
4. Сыйымдылық шегі; бас тартқаннан кейін орын босайды.
5. Эконом/бизнес билет полиморфизмі, қайталанған төлемге тыйым.
6. Төленген броньнан бас тартуға тыйым.
7. Кодты қалыпқа келтіру және текті тексеру.
8. Бөгде BookingService броньды өзгерте алмайды.
9. JSON round trip: CREATED/CANCELLED/CONFIRMED/CHECKED_IN, билет уақыты, баға және орын байланысы.
10. Бұзылған JSON тізімдерді де, файлды да өзгертпейді; қате себебі сақталады.
11. Файл жоқ болса null — жаңа үлгі деректер дайындауға белгі.
12. Бос өрістерге тыйым және шеткі бос орындарды алып тастау.
13. Қате сандарды қайта сұрау және бос таңдау аралығын қабылдамау.

Бұл тексерулер барлық ықтимал жағдайдың толық дәлелі емес. Нақты банк/рейс API жоқ; интерфейс консольдік, төлем шартты.
